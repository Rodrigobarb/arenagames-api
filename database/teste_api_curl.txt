- LISTAR JOGOS
curl -X GET http://localhost:3002/jogo

- BUSCAR JOGO POR ID
curl -X GET http://localhost:3002/jogo/1

- CADASTRAR JOGO
curl -X POST -H "Content-Type: application/json" -d "{\"nome\":\"Dota 2\",\"genero\":\"MOBA\"}" http://localhost:3002/jogo

- ALTERAR JOGO
curl -X PUT -H "Content-Type: application/json" -d "{\"id\":5,\"nome\":\"Dota 2\",\"genero\":\"MOBA / Estratégia\"}" http://localhost:3002/jogo

- REMOVER JOGO
curl -X DELETE http://localhost:3002/jogo/5

As mesmas operações existem para /equipe e /jogador
